ℹ️ Sobre la sincronización entre dispositivos

Este sistema guarda los datos en el navegador de cada dispositivo por separado (localStorage). Al ser un único archivo HTML sin servidor, no existe forma real de sincronizar automáticamente las ventas entre el celular de Toto, el de Mati y la PC de Manu — cualquier función que dijera lo contrario estaría simulando algo que no funciona de verdad.

Recomendación para las 5 noches: usen un solo dispositivo por vez como "caja" (por ejemplo, siempre el mismo celular), y descarguen un backup (.json) al cerrar cada noche. Si en algún momento quieren ver los datos desde otro dispositivo, exporten el backup y restáurenlo ahí. Para una sincronización real en tiempo real haría falta un servidor/base de datos externa, que está fuera del alcance de un archivo HTML autónomo.
